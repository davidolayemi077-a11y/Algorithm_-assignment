# Algorithm_-assignment
checkpoint
Algorithm to determine the length of the sentence

step 1: create a container to hold the sentence
step 2: create a container to hold the length of the sentence
step 3: read the sentence character by character and add 1 to the length of the sentence per character you count
step 4: print the length of the sentence

Algorithm to determine the number of words in the sentence

step 1: create a container to hold the sentence 
step 2: create a container to hold the word count
step 3: read the sentence character by character and add1 to each word seperated by a single space
step 4: print the number of words

Algorithm to determine the number of vowel in the sentence

step 1: create a container to hold the sentence
step 2: create a container to hold the vowel count
step 3: read the sentence character by character and add 1 to each after vowel count
step 4: print the number of vowels
